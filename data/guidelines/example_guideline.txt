## Assets / Large Deposits
A large deposit is any single non-payroll deposit above the threshold set by the lender (demo value 10,000 USD). The underwriter must obtain documentation that establishes the source of the funds, such as a transfer record, a sale receipt or a gift letter. Funds with no documented source must not be counted as available assets.
[Page 18]
## Income / Verification
Stated income must be supported by a recent pay stub. When income on the application differs from documented income, the underwriter reviews both figures and records the qualifying income used and why.
[Page 21]
## Employment / Verification of Employment
A written or verbal verification of employment is required for every employed borrower. The employer name should match across the application, pay stub and verification. Minor name variants must be confirmed.
[Page 30]
## Property / Appraisal Value
When the appraised value differs from the value stated on the application, the appraisal report is the reference value for LTV. The difference must be noted in the file.
[Page 36]
## Assets / Reserves and Funds to Close
Verified assets must cover the down payment and closing costs. Remaining verified assets are counted as reserves. Stated assets that differ from bank statements must be reconciled before the higher figure is used.
[Page 40]
## Conditions / Documentation Standards
Each condition must state what is needed, why it is needed and which document or finding it relates to. Conditions are cleared only when the underwriter reviews the submitted document.
